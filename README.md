# Интерактивный химический справочник с элементами геймификации («Mendeleev Lab»)

Кроссплатформенное мобильное приложение, разработанное на базе фреймворка **React Native** и **Expo SDK** в рамках производственной практики в учебном центре **«Geron»** (период: 17 марта – 1 июня 2026 г.). Представляет собой современный интерактивный инструмент для изучения периодической таблицы химических элементов Д. И. Менделеева, проверки знаний и симуляции лабораторных опытов.

## 🚀 Ключевой функционал

Приложение разделено на три основных независимых модуля:

1. **Интерактивная таблица Менделеева (Вкладка «Таблица»):**
   - Отображение элементов с динамической цветовой индикацией по физико-химическим группам.
   - **Real-time Filtering Engine:** Мгновенная фильтрация элементов по категориям (например, «Полуметаллы»).
   - **Dual-Field Search:** Регистронезависимый сквозной поиск элементов в реальном времени по символу (например, «Fe») или русскоязычному названию.
   - **Contextual Modal Preview:** Модальные карточки с детальным извлечением метаданных элемента (атомный номер, точная масса, физические свойства, биосовместимость и индустриальное применение).

2. **Модуль контроля знаний (Вкладка «Викторина»):**
   - Динамическое переключение уровней сложности химического тестирования.
   - Интерактивная игровая сессия с фиксацией набранных очков (`score`) и выводом итоговых результатов.

3. **Виртуальная химическая лаборатория (Вкладка «Лаборатория»):**
   - Среда симуляции синтеза сложных химических соединений на основе базовых элементов.
   - Система реактивного отслеживания прогресса и разблокировки коллекции молекул (`LAB_RECIPES`).
   - **Fallback-алгоритм:** Проверка рецептов на наличие неточных совпадений и встроенный триггер игровых достижений (`isAllDiscovered`) при 100% заполнении коллекции.

## 🛠 Технологический стек

- **Framework:** React Native (Component-Oriented Architecture)
- **Environment:** Expo SDK (Managed Workflow), Node.js Runtime
- **State Management:** React Hooks (`useState`, `useEffect`, `useMemo`)
- **Database:** Локальная автономная структурированная JSON-база данных (36 ключевых элементов с полным набором физико-химических свойств)
- **UI/UX:** Декларативная верстка Flexbox, SafeAreaView, StatusBar, TouchableOpacity
- **VCS:** Распределенная система контроля версий Git + GitHub
- **AI-Assisted Development:** Применение больших языковых моделей (LLM) для оптимизации алгоритмов синтеза, валидации JSON-структур и генерации документации.

## ⚙️ Инструкция по локальному развертыванию

Для запуска проекта на локальной рабочей станции и мобильном устройстве необходимо выполнить следующие шаги:

1. **Клонирование репозитория:**

```bash
   git clone [https://github.com/arthaslav/chem-periodic-table.git](https://github.com/arthaslav/chem-periodic-table.git)
   cd chem-periodic-table

```

2. **Установка системных зависимостей (Node.js пакетов):**

```bash
   npm install

```

3. **Запуск локального сервера сборщика Metro Bundler:**

```bash
   npx expo start

```

4. **Запуск на устройстве:**

- Установите приложение **Expo Go** на мобильное устройство (Android / iOS).
- Отсканируйте сгенерированный в терминале QR-код камерой смартфона или через интерфейс Expo Go.
- Проект автоматически скомпилируется и запустится на устройстве в режиме Hot Reloading.
